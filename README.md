# lampac-go

Go-реализация медиасервера **Lampac** — самостоятельный сервер для Lampa-клиентов:
агрегирует онлайн-источники (балансеры), проксирует и подписывает стримы,
раздаёт плагины Lampa, умеет торренты (TorrServer-балансер), IPTV, транскодинг,
DLNA, календарь релизов, Telegram-авторизацию и админ-панель.

## Возможности

- **/lite/(источник)** — Lampa-совместимый API онлайн-источников; десятки
  встроенных балансеров + пользовательские JS-модули (goja) и
  custom-балансеры-подпроцессы.
- **Прокси стримов** — `proxylink` шифрует URL (+нужные апстрим-заголовки) в
  `/proxy/{enc}`; изображения — через `/proxyimg` с кэшем и ресайзом.
- **Торренты** — интеграция с TorrServer, пул бэкендов с health-check и
  фейловером, поиск через JacRed/Rutracker.
- **TMDB-прокси** с кэшем метаданных и картинок.
- **IPTV** — глобальные и пользовательские плейлисты, EPG, health-check каналов.
- **Транскодинг** — ffmpeg (локально или на выделенном боксе), HLS/ABR.
- **Веб-плеер** (Shaka) с субтитрами (JASSUB), skip-интро, watch-party.
- **Авторизация** — Telegram-бот / пароль / анонимные сессии, группы доступа,
  привязка устройств, promo-коды.
- **Админ-панель** — источники, статистика балансеров, WAF, логи, кластер,
  конфиг, JS-модули, обновления.

## Сборка

Нужен Go 1.26+.

```bash
go build -o lampac-go ./cmd/lampac-go
```

или через make:

```bash
make build
```

## Запуск

```bash
cp config.example.toml config.toml   # отредактируйте под себя
./lampac-go
```

По умолчанию сервер слушает `:18118`. Адрес админ-панели генерируется при
первом старте и печатается в лог.

Некоторым источникам нужны собственные ключи/токены (например, Alloha и Mirage
требуют партнёрский токен) — без них эти источники просто не активны.

## Структура

- `cmd/lampac-go` — точка входа.
- `internal/httpapi` — HTTP-сервер, маршруты, резолв источников.
- `internal/litesrc` — встроенные балансеры (`/lite/*`).
- `internal/proxylink`, `internal/proxyapi` — шифрование и проксирование стримов.
- `internal/torrs`, `internal/torrbalancer` — торренты и пул TorrServer.
- `internal/tgauth` — Telegram-авторизация и бот.
- `internal/adminhttp` — админ-панель.
- `internal/jsmodules` — пользовательские JS-источники (goja).
- `plugins/`, `wwwroot/` — клиентские плагины Lampa и веб-клиент.
- `docs/` — дополнительная документация.

## Лицензия и ответственность

Проект предоставляется «как есть» для самостоятельного размещения. Вы сами
отвечаете за источники, которые подключаете, и за соблюдение законодательства
вашей юрисдикции.
